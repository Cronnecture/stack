# Stack

A collection of related repositories organized as submodules.

## Structure

This repository uses Git submodules to organize multiple related projects:

- Each component is maintained as a separate repository
- Submodules allow independent development while maintaining version relationships
- Easy to clone the entire stack or individual components

## Usage

```bash
# Clone with all submodules
git clone --recurse-submodules https://github.com/Cronnecture/stack.git

# If already cloned, initialize submodules
git submodule update --init --recursive
```
